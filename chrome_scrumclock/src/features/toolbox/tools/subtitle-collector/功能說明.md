# 影片字幕與筆記收集器 (SubtitleCollector) 功能說明

> **位置**：`chrome_scrumclock/src/features/toolbox/tools/subtitle-collector/`  
> **架構角色**：`chrome_scrumclock` 實用工具箱 (ToolboxHub) 擴充工具  
> **關聯獨立擴充功能**：`chrome_video speed plus`

---

## 1. 功能概述

「影片字幕與筆記收集器」是整合於 `chrome_scrumclock` 實用工具箱（ToolboxHub）的影音學習專用面板。其核心價值為：
1. **跨插件零摩擦同步**：
   - 即時接收並呈現由 `chrome_video speed plus` 於各大影音網站（如 YouTube）透過 `COLLECT_NOTE` 傳送之精選字幕片段與時間戳筆記。
   - 透過 `chrome.storage.onChanged` 實作多分頁即時響應，無須手動刷新。
2. **多維度檢索與過濾**：
   - 支援即時關鍵字模糊搜尋（涵蓋影片標題、字幕內文與時間戳記）。
   - 支援「全部 / 字幕 / 筆記」類型切換 Pills。
   - 動態提取標籤庫，支援多標籤篩選切換。
3. **學習轉任務閉環 (Actionable Knowledge)**：
   - **精準時間點跳轉**：點擊時間戳記徽章（例如 `01:23`）直接跳轉 YouTube 帶秒數連結 (`&t=Xs`)。
   - **一鍵 Markdown 導出**：快速複製為包含引言格式、標題來源與標籤的 Markdown 語法，利於貼至筆記軟體。
   - **轉為今日戰役任務**：一鍵將該字幕轉化為 ScrumClock 今日戰役任務 (`weeklyMissions` 與 `dailyLogs[today].coreBattles`)，將影音學習直接化為具體可執行的番茄鐘任務。

---

## 2. 元件結構

- `SubtitleCollector.tsx`：核心 UI 元件，包含指標統計、搜尋過濾、卡片流與轉任務邏輯。
- `types.ts`：定義 `CapturedSubtitleNote`、`SubtitleFilterState`、`SubtitleCollectorStats` 資料結構。
- `index.ts`：模組出口，提供乾淨的 Re-export。

---

## 3. 防腐與安全性規範

- **無危險 API**：不使用 `eval` 或 `dangerouslySetInnerHTML`，所有內容均透過 React 狀態安全渲染。
- **純相對路徑**：專案內部文檔全面維持簡潔純字串相對路徑，符合 SSOT 規範。
- **樣式統一**：嚴格遵循 ScrumClock 既有之 Tailwind 深色主題色彩變數（`bg-dark-surface`, `bg-dark-card`, `text-dark-primary` 等）。
