# 瀏覽行為監控器 (ActivityMonitor) 功能說明

> **位置**：`chrome_scrumclock/src/features/toolbox/tools/activity-monitor/`  
> **架構角色**：`chrome_scrumclock` 實用工具箱 (ToolboxHub) 擴充工具  
> **關聯獨立擴充功能**：[`../../../../browser-activity-monitor/`](../../../../browser-activity-monitor/README.md)

---

## 1. 功能概述

「瀏覽行為監控器」是整合進 `chrome_scrumclock` 實用工具箱的安全審查分頁。其設計目標為：
1. **當前分頁敏感權限審查**：一鍵檢測目前瀏覽中網頁的相機、麥克風、地理位置、桌面通知與剪貼簿授權狀態。
2. **安全監控日誌快照與來源透明化**：
   - 展示敏感 API 調用事件，支援按風險等級（低、中、高）篩選。
   - **來源識別歸屬 (Origin & Source Attribution)**：明確標記事件觸發者類型（🌐 網頁/網域、🧩 擴充功能識別、⚙️ 背景服務、🧪 模擬測試），滑鼠懸停可檢視完整 URL 或目標資源。
3. **一鍵複製 AI 診斷報告**：
   - 工具列提供「📋 複製 AI 報告」功能，一鍵將分頁上下文、風險統計與篩選後的日誌轉換為標準 Markdown 格式。
   - 包含內建 Prompt 指引，便於直接貼入 AI 助手獲取安全分析與防護建議。
4. **零依賴與防禦性降級**：
   - 保持與 `browser-activity-monitor` 獨立外掛的代碼零耦合。
   - 當獨立外掛未安裝時，以本機沙盒模式安全運作，提供模擬注入與介面操作體驗，絕不影響 ScrumClock 原有功能。

---

## 2. 元件結構

- `ActivityMonitor.tsx`：核心 UI 元件，包含權限卡片、狀態標籤、來源標記、一鍵複製與模擬控制列。
- `types.ts`：定義 `PermissionItem`、`ActivityAuditLog`（含 `sourceType`, `domain`, `targetUrl`）、`ExtensionStatus` 資料模型。
- `index.ts`：模組出口，提供乾淨的 Re-export。

---

## 3. 防腐與安全性規範

- **無危險 API**：不使用 `eval` 或 `innerHTML`，全數使用 React 狀態與受控元件渲染。
- **剪貼簿安全寫入**：使用標準 `navigator.clipboard.writeText`，並具備非同步錯誤防護與 2 秒視覺成功狀態反饋。
- **相對路徑規範**：所有文檔內部全面維持相對路徑，符合專案 SSOT 憲法。
- **樣式統一**：完全遵循 ScrumClock 既有之 Tailwind 深色主題色彩變數（`bg-dark-surface`, `bg-dark-card`, `text-dark-primary` 等）。
