# Scrumclock：個人目標與專案管理工作流指南 (Productivity Workflow Guide)

這份文件旨在規劃如何將 Scrumclock 擴充功能、Google Sheets、Google Tasks 與 Google Calendar 完美結合，打造一套適合高效工作者（10x Worker）的「目標管理、專案推進與每日執行」的自動化防禦系統。

---

## 🛠️ 1. 工具定位與架構 (The Ecosystem)

為了避免工具超載，我們明確定義每個工具在系統中的「唯一職責」：

| 工具 / 平台 | 系統定位 | 具體用途 |
| :--- | :--- | :--- |
| **Google Sheets** | 🧠 戰略控制中心 & 資料倉儲 | 儲存長期「北極星目標」、本週「核心專案」，以及備份所有的每日「衝刺日誌 (Sprint Logs)」與「回顧 (Review)」。 |
| **Google Tasks** | 📥 靈感收集箱 (Inbox) | 作為快速捕捉的緩衝區。處理零碎的突發待辦、瑣事，以及衝刺過程中的臨時靈感。 |
| **Google Calendar** | 🛡️ 時間防禦陣地 | 視覺化您的時間資產，透過自動建立不可打擾事件，阻擋他人的會議邀請。 |
| **Scrumclock 插件** | 🚀 專注執行引擎 (Execution) | 負責前線戰鬥：AI 任務拆解、番茄鐘倒數、封鎖分心網站，以及將成果自動派發回各個系統。 |

---

## 🔄 2. 高效工作流：PDCA 循環實踐

這套工作流從「週規劃」收斂到「日執行」，最後再進行「日回顧」。

### 階段一：【週規劃】確立戰略方向 (Plan)
每週一早晨或週日晚間，請專注於您的 **Google Sheets (`Tasks` 工作表)**：
1.  **校準北極星 (B1)**：確認本月/本季的終極目標（例如：`推出個人 SaaS 產品`）。
2.  **設定週任務 (B2 往下)**：列出為了達成北極星，本週**必須**推進的 3~5 個核心專案（例如：`完成金流 API 串接`、`撰寫 Landing Page 文案`）。
*   *原則：這裡只放「大石頭」，不放零碎瑣事。*

### 階段二：【晨間對齊】每日任務分流與 AI 拆解 (Align)
每天早上打開電腦的第一件事：
1.  **拉取戰略**：打開 Scrumclock 面板，點擊「🔄 同步」，將 Google Sheets 的「週任務」與 Google Tasks 的「瑣事」統一拉進今日儀表板。
2.  **AI 任務拆解**：面對如「完成金流 API 串接」這樣龐大且容易拖延的任務，直接點擊「✨ AI 幫我拆」或傳送至側欄助理。
    *   讓 AI 將其拆解為數個 25~50 分鐘可執行的子任務（例如：`閱讀 Stripe API 文件`、`實作 Checkout Session`）。
3.  **承諾時間**：選定今天真正要執行的任務，剩下的留在 Tasks 中不要管。

### 階段三：【深度工作】專注衝刺與時間防禦 (Do)
進入核心工作時段，讓 Scrumclock 接管：
1.  **啟動防護罩**：點擊開始番茄鐘 (Sprint)。
    *   *幕後自動化*：系統會自動發送 API 到 Google Calendar，在當下時段建立 `[Deep Work] 不可打擾` 事件。
    *   *網路防禦*：DNR 模組自動生效，若手癢打開 YouTube 或社群媒體，會被強制導向至 `blocked.html` 靜心頁面。
2.  **閃電捕捉 (Quick Capture)**：在寫 Code 進入心流時，如果突然想到「下班要買牛奶」或「剛才那個 Bug 可能是 Caching 問題」，**絕對不要切換視窗**。
    *   按下 `Alt + K`，輸入文字後 `Enter`。內容會無聲無息地進入 Google Tasks Inbox，您的心流不會被打斷。

### 階段四：【日終回顧】沉澱與數據累積 (Review)
結束一天工作時：
1.  **成果回顧**：點擊 Scrumclock 的「Review」按鈕。
2.  **提取教訓**：記錄今天最大的成就 (Highlight)、踩坑的教訓 (Lesson) 以及明天的下一步 (Next Action)。
    *   *幕後自動化*：這些資料會自動被寫入 Google Sheets 的 `Logs` 工作表中。長久下來，這會成為您個人專屬的「踩坑資料庫」，未來 AI 甚至能讀取這些日誌來預防您犯同樣的錯。
3.  **熱力圖激勵**：看著面板上的綠色方塊 (GitHub Heatmap) 又深了一點，帶著成就感下班。

## 🚀 3. 給您的客製化建議與下一步行動

如果您希望將這套系統發揮到極致，建議可以優先進行以下設定：

1.  **建立專屬您的試算表**：確保已依照 `google-apps-script.md` 部署了後台，並將 Sheets URL 貼入插件。
2.  **熟記兩大快捷鍵**：
    *   `Alt + K`：隨時隨地傾倒大腦垃圾至 Google Tasks。
    *   `Cmd + K` / `Ctrl + P`：打開指令列，雙手不離鍵盤啟動專注。
3.  **善用 AI 歷史回顧**：在讓 AI 拆解任務時，可以讓 AI 先閱讀您的 Google Sheets `Logs`（未來可擴充功能），讓 AI 提醒您：「上次做類似功能時，你在 CORS 上卡了兩小時，這次請先檢查 Headers。」
