瑞士刀架構元件分佈 (System Components)
🖥️ React 前端面板 Frontend
  • NewTabApp (焦點模式) / SprintPomodoro UI
    主操作介面，包含新分頁單一 MIT 焦點模式與原有的看板排序、拖曳等。
  • TimerContext
    全域計時狀態核心，統籌當前任務、時間倒數與狀態切換。
  • Web Audio API
    內建合成器，播放專注紅噪音（雨聲）以及頌缽結束共鸣聲。
💾 Chrome Storage Database
  • chrome.storage.local
    Chrome 瀏覽器原生本地持久化存儲，提供極速的資料存取。
  • activeTimer / todayMit (SSOT)
    計時器單一真理源，記錄今日唯一任務、剩餘時間、當前狀態與正在衝刺的任務。
  • weeklyMissions
    本週任務清單，包含任務內容、預估/已消耗番茄數與標籤。
⚙️ Background Worker Worker
  • background.ts
    Service Worker 背景腳本，負責監聽計時結束、發送桌面提示。
  • chrome.alarms (含午/晚間回顧)
    接管計時，並提供 13:30 與 21:00 的定時喚醒校準提醒。
  • declarativeNetRequest
    Chrome 網路層規則引擎，負責在專注模式下攔截並重導分心網站。
🛡️ 專注阻擋防線 Shield
  • blocked.html
    分心網站重定向目標頁。使用 onChanged 機制即時讀取 Storage 同步倒數。
🔌 外部 API 整合層 Integration
  • Notion Webhook
    將完成任務與反思筆記即時寫入 Notion 專屬任務看板資料庫。
  • GAS Apps Script
    Google 試算表日誌寫入 API，用於儲存衝刺與反思備份。
  • 原生 Google Tasks/Calendar API
    透過 OAuth 雙向同步今日 MIT 與時間塊至 Google 原生服務。

💡

架構設計亮點： 系統採用了 Google Chrome Extension 的單一真理源 (SSOT) 架構。當 Popup / Sidebar 等 React 前端被關閉時，計時工作會在瀏覽器核心背景 Service Worker 接管；使用者在攔截頁 blocked.html 依舊能即時看見倒數，完成了零斷裂的專注體驗。

番茄鐘狀態機轉移矩陣 (Pomodoro State Transition Matrix)
當前狀態 觸發事件 / 操作 目標狀態 前端表現 (聲音與畫面) 背景核心動作 (資料庫與網路阻擋)
Idle (閒置) 開始衝刺 (Start) Running (衝刺) 啟動 Web Audio 合成器播放紅噪音雨聲，UI 呈現紅色倒數。 寫入 activeTimer，調用 DNR **啟用社群網站阻擋**。設定背景計時鬧鐘。
Running (衝刺) 暫停衝刺 (Pause) Paused (暫停) 暫停雨聲白噪音，UI 轉為黃色，數字停止倒數。 暫停背景鬧鐘計時，調用 DNR **解除網站阻擋**（防線暫時放行）。
Paused (暫停) 繼續衝刺 (Resume) Running (衝刺) 重啟雨聲白噪音，UI 回復紅色倒數。 重設背景計時鬧鐘，調用 DNR **重新啟用網站阻擋**。
Running (衝刺) 計時結束 (Timer End) Logging (記錄) 雨聲停止，Web Audio 合成並播放**餘音頌缽音效**，UI 跳出成果記錄視窗。 解除網站阻擋（防線全面放開），網頁背景發送桌面完成通知。
Paused (暫停) 放棄衝刺 (Cancel) Idle (閒置) 停止所有音效，UI 重置回主畫面。 **清理 activeTimer**，確認停用網站阻擋規則，關閉背景鬧鐘。
Logging (記錄) 提交成果 (Log) Break (休息) 關閉成果視窗，UI 切換為綠色休息倒數。 成果寫入本地 `todayLog`，觸發 Notion & GAS Webhook 自動非同步同步。
Logging (記錄) 取消 (Reset) Idle (閒置) 重置回主畫面。 清理 activeTimer，回到閒置狀態。
Break (休息) 休息結束 (Break End) Idle (閒置) 播放休息結束提示音，UI 提示「準備開始下一場戰役」。 清理休息計時器狀態，等待使用者啟動新一輪番茄。
⏱️

狀態轉移安全機制： 在暫停（Paused）狀態下，網站阻擋會自動解除，方便使用者臨時查閱重要訊息；但放棄衝刺會徹底清除計時資料。在記錄成果（Logging）狀態下，防線已解除以利登錄筆記，只有點擊「提交成果」才會成功寫入資料庫並自動進入綠色的 Break 休息倒數，達成敏捷反思循環。

AI 週任務拆解與時間自動排程步驟表 (AI Sequence Steps)
步序 發起方 與 接收方 核心動作與資料負載 設計容錯與自動化機制
1
 使用者 ➔ React UI 在週任務列表上，對特定宏觀任務點選「🤖 拆解」按鈕。 觸發前端 Loading 骨架屏動畫，防止使用者重複點擊。
2
 React UI ➔ SyncService 調用 API 介面：`breakdownTask(taskId)` 傳入任務識別碼。 統一適配層 (ITaskAdapter) 以屏蔽底層遠端介面差異。
3
 SyncService ➔ Notion / GAS API 發送 POST 請求 `/ai_breakdown`，向大模型發起任務拆解。 使用非同步 AJAX Fetch API 並設定 5 秒超時機制。
4
 Notion / GAS API ➔ SyncService 回傳解析好的 JSON 陣列：包含子任務清單與 🍅 預估預算。 遠端 AI 分析並格式化為統一的 `[ { name: string, tomato: number } ]`。
5
 SyncService 內部降級 【降級容錯】 若 API 返回 503 錯誤或超時，啟動前端本地模擬。 自動容錯： 前端生成標準三步驟子任務（分析、開發、整合測試）確保功能不中斷。
6
 SyncService ➔ 使用者 回傳解析陣列，UI 彈出「AI 拆解預覽 Modal」。 使用者可在對話視窗上勾選需要匯入的特定子任務。
7
 使用者 ➔ React UI 使用者勾選好子任務，點擊「一鍵匯入今日戰役」按鈕。 將使用者手動確認後的子步驟推送至今日的行程列表中。
8
 React UI ➔ Chrome Storage 註冊並寫入週任務庫 `weeklyMissions` 作為關聯任務。 完成父任務與子任務的虛擬外鍵 (Parent ID) 綁定。
9
 React UI 內部排程算法 【自動排程演算法】 抓取今日任務最後一個結束時間點。 自動遞增： 抓取今日最晚結束時間（若無則為 `09:00`），依據 1 🍅 = 30分鐘（25分專注+5分休息），自動遞增計算並分配時段（例如：`09:00-09:30`）。
10
 React UI ➔ Chrome Storage 將賦予了排程時間段（committedTime）的子任務寫入今日 `coreBattles`。 今日核心戰役列表寫入完成，前端即時重新渲染，使用者不需手動填寫時間！
🤖

智能自動排程優勢： 這套演算法完成了從「宏觀拆解」到「微觀落地」的閉環。使用者不用再手動分配什麼任務在幾點執行，系統會抓取您今日最尾端的空閒時段，根據 AI 計算出的番茄數自動向後順延填寫，並且擁有 100% 的前端模擬 fallback 機制，無懼 CORS 與斷網風險。

AI 寫作輔助與剪貼簿無縫工作流步驟表 (AI Sidebar & Clipboard Flow)
步序 發起方 與 接收方 核心動作與資料負載 安全與使用者體驗亮點
1
 使用者 ➔ Google Docs 使用者在 Google Docs (或是任何編輯器) 選取並複製文字 (Ctrl+C)。 完全不用安裝 Google 官方 Add-on 或任何複雜整合。
2
 使用者 ➔ AISidebar 點擊 🤖 AI 專案助理 按鈕或按下快捷鍵 Ctrl+Shift+K 展開側邊欄。 側邊欄使用獨立 Shadow DOM 隔離 CSS，以防影響宿主網頁排版。
3
 AISidebar 偵測剪貼簿 側邊欄在背景偵測剪貼簿，並顯示剛才複製的「快取文字段落」。 極簡互動： 不用來回複製貼上，點擊即可直接做為 AI 優化標的。
4
 使用者 ➔ AISidebar 使用者點選優化快捷按鈕：✨ 潤色、📝 擴寫、📊 精簡 或 🌐 翻譯。 自動帶入針對該操作優化好的預設 System Instructions。
5
 AISidebar ➔ Chrome Storage 從 Storage 讀取儲存在本地的 geminiApiKey。 隱私安全： 金鑰只存在用戶瀏覽器，100% 掌握在用戶手中。
6
 AISidebar ➔ Google Gemini API 發送 POST 請求至 Gemini 官方 API (Gemini 1.5 Flash)。 直接在客戶端與 Google 通訊，免除架設後端與 Token 費用。
7
 Google Gemini API ➔ AISidebar API 回傳生成結果，側邊欄以極簡 Markdown Parser 即時渲染。 格式排版清晰，可讀性高，支援粗體、標題與條列清單。
8
 使用者 ➔ AISidebar 使用者滿意結果，點選下方 `📋 點擊複製貼回 Docs` 按鈕。 自動將生成文字再次寫入系統剪貼簿。
9
 使用者 ➔ Google Docs 在 Docs 選取原文，直接按下 Ctrl+V 覆蓋貼上。 Canvas 避讓設計： 完全繞過對 Google Docs Canvas DOM 結構的侵入與操作，穩定度達 100%。
✍️

Lite 專案助理優勢： 透過「剪貼簿快取偵測」與「一鍵複製貼回」機制的緊密配合，我們成功在「不侵入 Canvas、不申請官方 OAuth 2.0 敏感權限」的情況下，為 Max 創造了極佳的專案管理與任務拆解體驗，實踐了資深開發者以「最小技術改動，換取最大情境效益」的核心思維。
