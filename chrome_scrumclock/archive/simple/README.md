# 每日循環儀表板 - 簡化版

這是一個不需要 Node.js 的簡化版 Chrome 插件，可以直接安裝使用。

## 🚀 快速安裝

### 方法一：直接安裝（推薦）

1. 下載 `simple` 資料夾中的所有檔案
2. 打開 Chrome 瀏覽器
3. 在網址列輸入：`chrome://extensions/`
4. 開啟右上角的「開發人員模式」
5. 點擊「載入未封裝項目」
6. 選擇 `simple` 資料夾
7. 完成安裝！

### 方法二：使用安裝腳本

如果您有 Node.js 環境，可以運行：
```bash
cd chrome_scrumclock
npm install
npm run build
```

然後載入 `dist` 資料夾。

## 📋 使用流程

### 首次使用
1. 點擊插件圖示，選擇「設定」
2. 填寫基本資訊：
   - 使用者名稱
   - 北極星目標
   - 本週關鍵任務
   - 番茄鐘時長設定
   - 干擾網站列表
3. 儲存設定

### 每日使用
1. **早晨**：打開新分頁，完成「每日任務簡報」
2. **工作時**：使用「衝刺番茄鐘」執行核心戰役
3. **夜晚**：進行「日終回顧」，提煉洞見
4. **回顧學習**：查看「回顧紀錄」，從過去的反思中學習成長

## ✨ 主要功能

- **側邊欄導航**：隨時跳轉到不同功能頁面，提升使用體驗
- **每日任務簡報**：選擇今日核心戰役並設定時間
- **衝刺番茄鐘**：25分鐘專注計時器，自動阻擋干擾網站
- **成果記錄**：強制記錄每次衝刺的具體產出
- **日終回顧**：自動匯總成果，提煉洞見
- **回顧紀錄**：查看歷史回顧記錄，支援過濾和匯出功能
- **專注模式**：自動阻擋預設的干擾網站
- **響應式設計**：支援桌面和行動裝置

## 📚 回顧紀錄功能

### 功能特色
- **歷史記錄查看**：查看所有過去的日終回顧記錄
- **時間過濾**：支援按週、月、季或全部記錄查看
- **統計資訊**：顯示每日的核心戰役數、衝刺次數、專注時間
- **內容展示**：完整顯示高光時刻、最大教訓、明日關鍵行動
- **資料匯出**：支援匯出為 CSV 檔案，方便備份和分析

### 使用方式
1. 點擊側邊欄的「回顧紀錄」
2. 選擇時間範圍過濾器
3. 瀏覽歷史回顧記錄
4. 點擊「匯出記錄」下載 CSV 檔案

### 資料儲存
- 所有回顧記錄儲存在本地 Chrome Storage
- 資料不會上傳到任何伺服器
- 支援跨瀏覽器同步（如果啟用 Chrome 同步）

## 🔧 故障排除

### 無法載入插件
- 確保所有檔案都在同一個資料夾中
- 檢查 `manifest.json` 檔案是否完整
- 確認 Chrome 版本支援 Manifest V3

### 圖示載入錯誤
如果出現「無法載入圖示」錯誤：
1. 雙擊開啟 `create_icons.html` 檔案
2. 點擊「生成圖示」按鈕
3. 點擊每個圖示下方的「下載」按鈕
4. 將下載的 PNG 檔案（icon16.png, icon48.png, icon128.png）放在 `simple` 資料夾中
5. 回到 Chrome 擴充功能頁面，點擊插件的「重新載入」按鈕

### 專注模式不工作
- 檢查是否已授予「腳本」權限
- 確認干擾網站設定正確
- 重新載入插件

### 資料遺失
- 所有資料儲存在本地，不會遺失
- 如果遇到問題，可以清除瀏覽器資料後重新設定

## 📝 注意事項
