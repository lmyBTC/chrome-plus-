# 🌐 Chrome Plus - 統一 Google Apps Script (GAS) 雲端數據匯流部署指南

本手冊提供一步步完整的設定流程，協助您建立專屬的 Google 雲端戰情室，將 **ScrumClock（番茄鐘與任務管理）** 與 **FinanceClipper（投資研究與研報擷取）** 的數據無縫匯流至同一個 Google 試算表。

## 1. 架構概覽

```
┌────────────────────────┐      ┌────────────────────────┐
│      ScrumClock        │      │     FinanceClipper     │
│ (專注番茄鐘 / 衝刺 Log) │      │ (財務指標 / 個股研報)   │
└───────────┬────────────┘      └───────────┬────────────┘
            │ action: 'scrum_sync'          │ action: 'finance_clip' / 'batch'
            └───────────────┬───────────────┘
                            │ (HTTPS POST + Secret Token)
                            ▼
              ┌───────────────────────────┐
              │  Unified GAS Router       │
              │  (unified_gas_router.gs)  │
              └─────────────┬─────────────┘
                            │
       ┌────────────────────┼────────────────────┐
       ▼                    ▼                    ▼
┌──────────────┐    ┌───────────────┐    ┌───────────────────────────┐
│  Tasks_Log   │    │Stocks_Research│    │Productivity_Cross_Analysis│
│ (藍色 分頁)   │    │  (綠色 分頁)  │    │  (紫色 自動交叉量化模型)    │
└──────────────┘    └───────────────┘    └───────────────────────────┘
```

- **統一單一網址**：雙插件使用同一個 Webhook URL，由後端 GAS 自動判讀 Payload 進行智慧分流。
- **100% 私有安全**：所有數據直接從您的 Chrome 瀏覽器傳送至您自己的 Google 帳號，不經過任何第三方雲端轉發。
- **免手動建表**：第一次發送資料時，GAS 會自動建立分頁、凍結首行、配置品牌配色與動態計算公式。

## 2. 第一階段：建立 Google 試算表與部署 Apps Script

### 步驟 2.1：建立空白試算表
1. 開啟 [Google 雲端硬碟](https://drive.google.com/) 或 [Google 試算表](https://sheets.new/)。
2. 建立一份新的空白試算表，並命名為：
   > **`Chrome Plus 雲端數據戰情室`**

### 步驟 2.2：開啟 Apps Script 編輯器
1. 在試算表上方選單點選 **「擴充功能」 (Extensions)** ➔ **「Apps Script」**。
2. 將預設專案名稱 `未命名專案` 改為 `Chrome_Plus_Unified_Router`。

### 步驟 2.3：貼上後端腳本
1. 清空編輯器中原本的 `function myFunction() {}`。
2. 將專案中的 [`unified_gas_router.gs`](./unified_gas_router.gs) 內容完整複製並貼入編輯器。
3. 點擊工具列的 **「儲存」💾** (或按 `Ctrl + S`)。

### 步驟 2.4：(推薦) 設定安全性金鑰 (Secret Token)
為防止未授權人士胡亂寫入您的試算表，可設定一把自訂密鑰：
1. 在 Apps Script 左側邊欄點選 **「專案設定」⚙️** (齒輪圖示)。
2. 向下滾動至 **「指令碼屬性」 (Script Properties)**，點擊 **「新增指令碼屬性」**。
   - **屬性 (Property)**：`SECRET_TOKEN`
   - **值 (Value)**：自行設定一組高強度字串（例如：`my_super_secure_token_2026`）
3. 點擊 **「儲存指令碼屬性」**。
> [!NOTE]
> 若不設定此屬性，系統將預設為開放寫入模式（仍可正常運作，但建議配置以確保資安）。

### 步驟 2.5：發布為 Web 應用程式 (Web App)
1. 點擊右上角藍色的 **「部署」 (Deploy)** ➔ **「新增部署」 (New deployment)**。
2. 點擊左側「選取類型」齒輪 ⚙️，選擇 **「網路應用程式」 (Web app)**。
3. 填寫部署設定（**非常重要，請務必按照下方設定**）：
   - **說明 (Description)**：`Chrome Plus Unified Router v1.0`
   - **以何身分執行 (Execute as)**：**`我 (您的 Gmail 帳號)`**
   - **誰可以存取 (Who has access)**：**`任何人 (Anyone)`** *(注意：若選成「僅限自己」，Chrome 插件在發送非同步請求時會因為未授權而失敗！)*
4. 點擊 **「部署」 (Deploy)**。

### 步驟 2.6：授權存取
初次部署時，Google 會要求授權以允許腳本存取您的試算表與 Google 雲端硬碟（用於存儲圖表截圖）：
1. 彈出「需要授權」視窗，點擊 **「審查權限」 (Authorize access)**。
2. 選擇您的 Google 帳號。
3. 若出現「Google 尚未驗證此應用程式 (Google hasn't verified this app)」警示頁面：
   - 點擊左下角 **「進階」 (Advanced)**。
   - 點擊 **「前往 Chrome_Plus_Unified_Router (不安全) / Go to ... (unsafe)」**。
4. 點擊 **「允許」 (Allow)** 完成授權。

### 步驟 2.7：取得 Web 應用程式網址 (Web App URL)
1. 部署完成後，複製畫面上顯示的 **網頁應用程式網址 (Web app URL)**。
   - 格式應類似：
     `https://script.google.com/macros/s/AKfycbx.../exec`
   > [!IMPORTANT]
   > 網址結尾必須是 `/exec`，而非 `/dev`！請妥善保存此 URL。

## 3. 第二階段：外掛端配置 (ScrumClock & FinanceClipper)

### 3.1 配置 ScrumClock
1. 點開 Chrome 右上角 **ScrumClock** 插件圖示。
2. 點擊右上角 **設定齒輪 ⚙️** 開啟設定面板。
3. 滾動至 **「Google Sheets 雲端戰情室同步」** 區塊：
   - **Webhook URL**：貼上在步驟 2.7 取得的 Web App URL。
   - **Secret Token**：輸入在步驟 2.4 設定的密鑰（若無設定可留空）。
   - **啟用自動同步**：勾選「專注週期完成時自動同步」。
4. 點擊 **「連線測試」** 驗證，成功後點擊 **「儲存設定」**。

> [!TIP]
> **標的代碼自動關聯技巧**：
> 在 ScrumClock 建立專注任務時，只要任務名稱或標籤中包含 `$NVDA`、`$2330` 或 `#TSLA`，系統便會自動提取個股代碼，並在雲端交叉分析表中精準對應！

---

### 3.2 配置 FinanceClipper
1. 點開 **FinanceClipper** 插件之 **Sidepanel** 或 **Popup**。
2. 點擊右上角 **設定 ⚙️** (或儀表板設定)。
3. 在 **「雲端匯流設定 (GAS Webhook)」** 欄位：
   - 貼上相同的 **Web App URL**。
   - 填寫相同的 **Secret Token**。
4. 點擊 **「儲存設定」**。
5. **資料同步**：
   - **單筆研報**：在瀏覽個股財務頁面並記錄筆記後，點擊「同步至試算表」，立即寫入。
   - **批次同步**：開啟「自選股研報儀表板 (Dashboard)」，點擊「批次同步所有追蹤標的」，一次將歷史研報打包上傳。

## 4. 第三階段：戰情室三大分頁與交叉分析說明

當您第一次從外掛發送數據後，Google 試算表會自動建立以下三個結構完整的分頁：

### 📘 分頁 1：`Tasks_Log` (專注與衝刺紀錄)
- **色標**：Google 藍 (`#1a73e8`)
- **欄位**：`UUID` | `完成時間` | `任務名稱` | `標的代碼` | `標籤` | `完成番茄數` | `預估番茄數` | `總時長(分鐘)` | `狀態` | `執行備註` | `來源`
- **特點**：
  - 個股專注任務（含代碼）會自動以淡金色標記行高亮。
  - 首行凍結與邊框美化。

### 📗 分頁 2：`Stocks_Research` (研報與財務筆記)
- **色標**：清新綠 (`#0d904f`)
- **欄位**：`UUID` | `研究時間` | `Ticker` | `公司名稱` | `當前價格` | `分析師評級` | `目標價` | `研究情緒` | `分析筆記` | `本益比` | `市值` | `圖表截圖` | `大盤表現` | `研報連結`
- **特點**：
  - 圖表截圖自動轉為 Google Drive 共享圖片並產生點擊連結。
  - 看多 / 看空自動以紅綠色彩強調。

### 🔮 分頁 3：`Productivity_Cross_Analysis` (量化交叉分析模型)
- **色標**：星空紫 (`#8430ce`)
- **核心報表欄位**：
  - `標的代碼`：自動聯集並排序出現在雙插件之所有標的。
  - `研報次數`：`COUNTIF` 動態統計該標的產出之分析篇數。
  - `投入番茄鐘總數`：`SUMIF` 統計在 ScrumClock 中為該標的專注的番茄鐘個數。
  - `總專注時長(小時)`：換算小時數。
  - `最新股價` & `目標價` & `潛在空間 (%)`：透過 `XLOOKUP` 動態抓取最新數據並計算預期漲跌幅。
  - `研究效益評估`：自動劃分 `🔥 深度核心配置 (≥6🍅)`、`⭐ 重點關注 (2-5🍅)`、`🌱 初步靈感 (1🍅)`。
- **側邊戰情排行榜 (K1:M7)**：
  - 透過 `QUERY` 公式，動態展示 **「Top 5 累計專注時長標的」**，一眼看出時間投入在哪些核心資產。

### 🛠️ 試算表上方專屬選單
在試算表頂端工具列會出現 **「📊 Chrome Plus 戰情室」** 選單：
- **`🔄 重新整理交叉分析模型`**：若手動修改過公式或分頁，點擊此按鈕可一鍵自動修復所有動態陣列公式與樣式。
- **`📋 初始化所有分頁`**：在尚未發送任何 Webhook 前，可手動先預先建置好三張空表。

## 5. 常見問題與故障排查 (FAQ)

### Q1：外掛顯示「網路錯誤」或「401 未授權」？
- **原因**：Secret Token 與 Apps Script 中的 `SECRET_TOKEN` 不一致。
- **排除**：檢查外掛輸入的 Token 是否與 Apps Script「專案設定」中的指令碼屬性完全吻合（注意大小寫與前後空白）。

### Q2：外掛顯示「存取遭拒」或回傳 HTML 登入頁面？
- **原因**：部署 Web App 時，「誰可以存取 (Who has access)」設定錯誤。
- **排除**：
  1. 在 Apps Script 點選右上角「部署」➔「管理部署」。
  2. 點選鉛筆編輯圖示，確認「誰可以存取」已設為 **「任何人 (Anyone)」**。
  3. 版本選擇「新版本」，點擊部署即可。

### Q3：更新 `unified_gas_router.gs` 程式碼後，為什麼試算表沒有反應？
- **原因**：Apps Script 在修改程式碼後，**必須建立「新版本部署」**才會生效！
- **排除**：
  1. 點擊右上角「部署」➔「管理部署」。
  2. 點擊鉛筆 ✏️ 編輯。
  3. 「版本」下拉選單選擇 **「新版本」 (New version)**。
  4. 點擊「部署」。

### Q4：Google Drive 中的截圖會佔用很多空間嗎？
- 插件在上傳圖表前已經過壓縮處理，每張截圖約 50KB ~ 150KB，存放在雲端硬碟的 `Chrome_Plus_Screenshots` 資料夾中，若空間不足可隨時手動清理舊截圖。
