## 2. 策略與鎖定檔案

### 核心規劃策略
1. **全景導覽與快速上手**：提供 Chrome 開發者模式載入插件指引，簡明標記各插件定位與入口。
2. **各模組核心功能詳解**：
   - `chrome_scrumclock` (ScrumClock 敏捷工作站)：看板管理、番茄鐘、AI 側邊欄、工具箱與活動監控。
   - `finance-research-clipper-oss` (FinanceClipper 研報採集)：多來源財報與籌碼採集、匯出、分析卡片。
   - `chrome_video speed plus` (Video Speed Plus)：極速無段倍速、A-B 循環、快捷鍵對照。
3. **高效複合玩法與工作流（重點章節）**：
   - 工作流 A【研報採集 + AI 研析 + 敏捷看板閉環】：FinanceClipper 抓取 -> 跨插件推至 ScrumClock AI -> 自動生成任務與自選股。
   - 工作流 B【影音極速學習 + 行動拆解】：Video Speed Plus 倍速播放 -> A-B 循環精華 -> ScrumClock 側邊欄同步筆記。
   - 工作流 C【深度專注 + 行為軌跡審計】：ScrumClock 番茄鐘專注 -> Activity Monitor 背景監控與分頁軌跡分析。
4. **常見疑難與故障排除 (FAQ)**：提供權限許可、跨插件通訊未響應時的排查手段。
