## 1. 目標
本任務為全景體驗與規格規劃之 Master Epic 總綱。為確保執行品質與遵循三階段守門門禁（Gate 2 原子化執行），本任務已依業務角色與技術領域分拆為 3 個獨立子 Task，各 Task 擁有適當大小之 Phase 子任務。

## 2. 子任務拆解清單與執行導航

各子任務均具備獨立之 Phase 劃分、鎖定檔案、SSOT 衝擊評估與跨會話接力指令：

1. **子任務 1：專案經理 (PM) 敏捷衝刺與工時軌跡工作流體檢**
   - 檔案：0.doc_mg/tasks/task_20261003_global_pm_workflow_friction_analysis.md
   - 焦點：ScrumClock + ActivityMonitor 協同、敏捷排程、番茄鐘衝刺、工時審查與斷點矩陣產出。
   - 規模：4 個 Phase（排程衝刺、軌跡審查、斷點挖掘、功能真空區盤點）。

2. **子任務 2：投資研究員 (Analyst) 法說會與財報研報工作流體檢**
   - 檔案：0.doc_mg/tasks/task_20261003_global_analyst_workflow_friction_analysis.md
   - 焦點：VideoSpeedPlus + FinanceClipper 協同、法說會倍速快篩、字幕轉任務、財務指標爬蟲與斷點矩陣產出。
   - 規模：4 個 Phase（影音快篩、財報擷取、斷點挖掘、功能真空區盤點）。

3. **子任務 3：跨插件 Google 生態系自動化對接架構設計與規格制定**
   - 檔案：0.doc_mg/tasks/task_20261003_global_google_ecosystem_integration.md
   - 焦點：Google Sheets / Docs / Calendar / Drive 統一對接藍圖、GAS vs OAuth2 選型、通訊合約擴充與整合規格書。
   - 規模：4 個 Phase（架構評估、通訊合約、規格書編寫、手冊更新與 SSOT 閉環）。
