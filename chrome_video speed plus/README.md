# YouTube Speed Plus - Chrome 擴充功能

這是一個讓您能夠將 YouTube 影片播放速度提升到 3 倍以上的 Chrome 擴充功能。

## 功能特色

- 🚀 支援 0.25X, 0.5X, 0.75X, 1X, 1.5X, 2X, 3X 的快速速度選擇
- ⚡ 自訂速度設定（0.1x 到 16x）
- 🔁 影片循環播放（支援自訂循環次數與 A-B 段落區間循環）
- 🎯 美觀的使用者介面
- ⌨️ 鍵盤快捷鍵支援
- 📱 即時速度提示
- 🔄 自動適應 YouTube 頁面變化

## 安裝步驟

### 1. 下載擴充功能檔案
確保您有以下檔案：
- `manifest.json`
- `popup.html`
- `popup.js`
- `content.js`

### 2. 圖示設定（可選）
如果您想要自訂圖示：
1. 開啟 `create_icons.html` 檔案
2. 右鍵點擊圖示，選擇「另存圖片」
3. 將檔案儲存為 `icon16.png`、`icon48.png`、`icon128.png`
4. 將這些檔案放在擴充功能資料夾中
5. 在 `manifest.json` 中取消註解圖示設定

### 3. 在 Chrome 中載入擴充功能

1. 開啟 Chrome 瀏覽器
2. 在網址列輸入 `chrome://extensions/`
3. 開啟右上角的「開發人員模式」
4. 點擊「載入未封裝項目」
5. 選擇包含擴充功能檔案的資料夾
6. 擴充功能應該會出現在擴充功能列表中

### 4. 開始使用

1. 前往任何 YouTube 影片頁面
2. 點擊瀏覽器工具列中的擴充功能圖示
3. 選擇您想要的速度或輸入自訂速度
4. 影片會立即調整到指定速度

## 使用方法

### 透過彈出視窗
- 點擊擴充功能圖示開啟控制面板
- 選擇預設速度（0.25x, 0.5x, 0.75x, 1x, 1.5x, 2x, 3x）
- 或輸入自訂速度（0.1x 到 16x）
- **設定循環播放**：可指定連續播放次數（填入 0 代表無限次循環）。
- **A-B 段落循環**：輸入秒數或是透過按鈕擷取當前播放時間作為「起點」與「終點」，點擊「開始循環」即可在該區間內不斷播放。

### 鍵盤快捷鍵
在 YouTube 頁面使用以下快捷鍵：
- `Ctrl + Shift + 1`: 設定為 1x 速度
- `Ctrl + Shift + 2`: 設定為 2x 速度
- `Ctrl + Shift + 3`: 設定為 3x 速度
- `Ctrl + Shift + 4`: 設定為 4x 速度
- `Ctrl + Shift + 5`: 設定為 5x 速度

## 技術細節

### 檔案說明

- **manifest.json**: 擴充功能的配置檔案，定義權限和基本資訊
- **popup.html**: 彈出視窗的 HTML 結構和樣式
- **popup.js**: 彈出視窗的 JavaScript 邏輯
- **content.js**: 在 YouTube 頁面中執行的內容腳本
- **create_icons.html**: 圖示生成器（可選）

### 核心功能

1. **影片元素偵測**: 自動尋找 YouTube 頁面中的 HTML5 影片元素
2. **速度控制**: 透過 `playbackRate` 屬性控制播放速度
3. **頁面監聽**: 監聽 YouTube SPA 的頁面變化
4. **訊息傳遞**: 在 popup 和 content script 之間傳遞訊息

### 安全性

- 只會在 YouTube 網域執行
- 使用 Manifest V3 標準
- 最小權限原則

## 疑難排解

### 擴充功能無法載入
- 確認所有檔案都在同一個資料夾中
- 檢查 `manifest.json` 格式是否正確
- 重新載入擴充功能

### 圖示載入錯誤
- 如果出現圖示載入錯誤，可以：
  1. 使用 `create_icons.html` 生成圖示檔案
  2. 或移除 `manifest.json` 中的圖示設定（已預設移除）

### 速度設定無效
- 確認您在 YouTube 影片頁面
- 重新整理頁面後再試
- 檢查瀏覽器控制台是否有錯誤訊息

### 快捷鍵無效
- 確認您在 YouTube 頁面
- 檢查是否有其他擴充功能衝突
- 重新載入頁面
